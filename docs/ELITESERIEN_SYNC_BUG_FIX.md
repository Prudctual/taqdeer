# توثيق المشكلة والحل: إصلاح خطأ مزامنة أندية الدوري النرويجي (Eliteserien Sync & Prediction Engine Fix)

## 📌 ملخص المشكلة (Problem Overview)
لاحظ المستخدم عدم منطقية توقعات نموذج «تقدير» لمباراة **أوليسوند × ترومسو**، حيث توقع النموذج فوز أوليسوند (صاحب المركز 13) بنسبة 44.4% وترجيح فوز ترومسو (صاحب المركز 3) بنسبة 30.6% فقط رغم التفوق الفني والكبير لترومسو وسلسلة انتصاراته الأخيرة.

---

## 🔍 التحقيق والجذر التقني للمشكلة (Root Cause Analysis)

عند فحص البيانات وقاعدة بيانات المشروع (`data/taqdeer.db`) وكود مزامنة الدوري النرويجي (`scripts/sync-eliteserien.ts`)، تبين ما يلي:

1. **اختلاف رموز الأندية بين المصادر (Team Code Mismatch):**
   * المصدر الخارجي (ويكيبيديا والاتحادات الكروية) يُرمز لفرق الدوري النرويجي برموز معيارية مختلفة، مثل:
     * ترومسو: `TIL` (Tromsø IL)
     * ساربسبورغ 08: `S08`
     * فوليرينغا: `VIF`
     * روزنبرغ: `RBK`
     * ليلستروم: `LSK`
     * كريستيانسوند: `KBK`
     * فريدريكستاد: `FFK`
   * في المقابل، كانت الخريطة داخل المنصة تعتمد رموزاً مختلفة (`TRO`, `SAR`, `VAL`, `ROS`, `LIL`, `KRI`, `FRE`).

2. **استبعاد النتائج التاريخية لـ 7 أندية من أصل 16:**
   * عند قيام كود المزامنة بفرز نتائج الدوري المكتملة، تسبب شرط عدم تطابق الكود (`if (!NORWAY_TEAMS[homeCode] || !NORWAY_TEAMS[awayCode]) continue;`) في **استبعاد وتجاهل جميع المباريات المكتملة لـ 7 أندية كاملة بالدوري**!
   * دخل فريق ترومسو إلى المحرك بـ **0 مباراة تاريخية مسجلة**.

3. **الآثار الناتجة في النماذج الإحصائية:**
   * **نموذج Form:** افترض أن ترومسو لم يسجل أي هدف خارج أرضه (`0.0 هدف/مباراة`) لعدم وجود مباريات مسجلة.
   * **نموذج Elo:** أعطى ترومسو التصنيف الافتراضي المبدئي (`1500.0` نقطة) بدلاً من مقياس قوته الحقيقي.
   * **النتيجة:** انخدعت خوارزمية التوقعات وأعطت الترجيح لصاحب الأرض أوليسوند.

## 🛠️ خطوات الحل (Resolution Steps)

1. **تعديل كود المزامنة (`scripts/sync-eliteserien.ts`):**
   * إضافة خريطة تحويل الرموز `CODE_ALIAS_MAP` لتطابق كافة الاختصارات.
   * تطوير دالة `normalizeCode` لتوحيد الرموز تلقائياً إلى الكود المعياري الموحد للمشروع (`TRO`, `SAR`, `VAL`, `ROS`, `LIL`, `KRI`, `FRE`).

```typescript
export const CODE_ALIAS_MAP: Record<string, string> = {
  TIL: "TRO",
  S08: "SAR",
  VIF: "VAL",
  RBK: "ROS",
  LSK: "LIL",
  KBK: "KRI",
  FFK: "FRE",
};

export function normalizeCode(code: string): string {
  const upper = code.toUpperCase();
  return CODE_ALIAS_MAP[upper] || upper;
}
```

2. **تنظيف قاعدة البيانات وتطهير الإدخالات المكررة:**
   * إعادة إسناد اللاعبين في جدول `players` إلى المعرفات الرسمية الموحدة.
   * إزالة صفوف الأندية المكررة والمهجورة ذات الـ 0 مباراة من جدول `teams`.

3. **إعادة تشغيل سكريبت المزامنة وحفظ المباريات:**
   * ارتفع عدد المباريات المسجلة في الدوري النرويجي من **4 مباريات** إلى **123 مباراة تاريخية كاملة**.

4. **إعادة تدريب وحساب التوقعات (`scripts/fit-and-predict.py`):**
   * تشغيل خوارزمية **Ensemble-v3** لإعادة حساب نماذج (Dixon-Coles, Elo, Pi-Ratings, Form, Market) بناءً على السجل التاريخي الشامل.
