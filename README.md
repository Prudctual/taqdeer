# تقدير (Taqdeer)

تحليلات وتوقع مباريات **دوريات أوروبية** (الخمس الكبرى + البرتغال + هولندا) — عربي كامل RTL.

الاحتمالات مشتقة من نماذج إحصائية شفافة على نتائج حقيقية، وكل رقم قابل للتتبع إلى نموذجه
ومصدره. `/accuracy` يعرض دقة النموذج على بيانات لم يرها أثناء التدريب.

## النماذج (ensemble-v4)

| الإشارة | الوزن الافتراضي | المصدر |
|---------|-------|--------|
| Dixon–Coles + تلاشٍ زمني (MLE عبر SciPy) | 0.34 | آخر ~1000 نتيجة |
| Pi-ratings ديناميكية (هجوم/دفاع) | 0.14 | نفس النتائج |
| Elo بهامش الأهداف (HA من بروفايل الدوري) | 0.14 | نفس النتائج |
| فورم متعدد النوافذ (3/5/10) + ازدحام | **0.20 (ثابت)** | نفس النتائج |
| سوق حاد (Pinnacle/PS ثم Avg) بعد إزالة الهامش | 0.11 | football-data + API-Football |
| سياق λ بعد التعديلات (context) | 0.07 | H2H / عشب / تكتيك / طقس / لاعبين / حكم |

**الفورم مقفول عند 20٪** من المزيج النهائي دائماً. بقية الأوزان (80٪) تُتعلَّم لكل دوري
(stacking). وإلى جانب DC على الأهداف يعمل **DC موازٍ على التسديدات** و**DC على xG تتبّعي**
(Understat للخمس الكبرى؛ الدوريات الأخرى تبقى على shot-proxy).

يتضمن المحرك أيضاً:
- **تأثير لاعب/تشكيلة**: قوة نسبية × مركز × حالة، مع XI delta عند تأكيد التشكيلة.
- **ازدحام الكؤوس**: خصم أقوى عند ≥3 مباريات خلال 7 أيام.
- **بداية الموسم**: K أعلى لـ Elo + خفض وزن DC + حرارة أعلى خلال ~60 يوماً.
- **CLV**: مقارنة الاحتمال العادل بخط الإغلاق الحاد.
- **أسواق O2.5/BTTS**: حرارة ثنائية منفصلة بعد محاذاة 1X2.
- **موديل حي**: شدة زمنية + حالة نتيجة + ρ خفيف + بدل ضائع + طرد.

ثم **temperature scaling** معاير على walk-forward، ثم تُوفَّق مصفوفة النتائج مع 1X2.
حيث تتوفر أسعار السوق يُحسب **+EV وحصة كيلي الربعية** (نطاق ‎3–15%‎).

**نزاهة التقييم:** المقاييس في `/accuracy` من اللبّ الإحصائي بلا طقس/إصابات (منع تسريب).
xG التاريخي وclosing بعد الصافرة مسموحان كبيانات مباراة مكتملة.

## البيانات

- نتائج تاريخية: [football-data.co.uk](https://www.football-data.co.uk/)
- xG تتبّعي: Understat (الخمس الكبرى)
- جداول الموسم: fixturedownload.com (+ أودز قادمة من fixtures.csv و API-Football)
- إثراء: FotMob (غيابات/تشكيلات) · Open-Meteo (طقس) · إحداثيات الملاعب في `scripts/data/stadiums.json`
- الشعارات: TheSportsDB → `public/crests`

قاعدة البيانات: `data/taqdeer.db`.

## التشغيل

يتطلب Node ‏22–24 (`.nvmrc`).

```bash
cp .env.example .env          # FOOTBALL_DATA_API_KEY · API_FOOTBALL_KEY · Telegram اختياري

python3 -m venv .venv
.venv/bin/pip install -r requirements.txt

bun install
bun run pipeline              # مزامنة → تدريب وتوقع
bun run enrich                # أودز/طقس/FotMob/Understat xG
bun run dev                   # http://localhost:3000
```

| الأمر | الوظيفة |
|-------|---------|
| `bun run sync` | مصادر + جدول + كروت + مقالات + أخبار |
| `bun run enrich` | دورة إثراء (أودز/طقس/FotMob/xG) |
| `bun run fit` | تدريب النماذج وكتابة التوقعات |
| `bun run repredict` | إعادة توقع المباريات ذات التشكيلة المؤكدة |
| `bun run check` | فحوص TS + `python -m engine.selftest` + eslint |
| `bun run telegram` | بوت أوامر؛ البث التلقائي بـ `TELEGRAM_BROADCAST=1` |

## حدود معروفة

- الدقة الإجمالية على walk-forward ≈ مستوى متقدم لثلاثة احتمالات؛ لا ضمان.
- xG التتبّعي يغطي الخمس الكبرى فقط؛ الباقي shot-proxy.
- PPDA تقريبي / تأثير اللاعب من دقائق التشكيلة — ليست بيانات Opta كاملة.
- الأودز والإثراء تغطي النافذة القريبة (أيام–أسبوعين) لا كل مباريات الموسم دفعة واحدة.
- الفرق الصاعدة تُبذر من متوسط تقييمات الهابطين لا من 1500 الأعمى.
