# تقدير (Taqdeer)

تحليلات وتوقع مباريات **دوريات أوروبية** (الخمس الكبرى + البرتغال + هولندا) — عربي كامل RTL.

الاحتمالات مشتقة من نماذج إحصائية شفافة على نتائج حقيقية، وكل رقم قابل للتتبع إلى نموذجه
ومصدره. `/accuracy` يعرض دقة النموذج على بيانات لم يرها أثناء التدريب.

## النماذج (ensemble-v5)

المبدأ (خطة `plans/006`): دقة أعلى تأتي من إشارة أنظف + إرساء على السوق الحاد + غربال
صارم + حلقة تغذية راجعة — لا من نموذج أعقد. سقف 1X2 الواقعي ~50–55٪.

**اللبّ (pm)** — خمس إشارات بأوزان softmax تُتعلَّم لكل دوري على مواسم كاملة ثم حرارة مُتعلَّمة:

| الإشارة | المصدر |
|---------|--------|
| Dixon–Coles + تلاشٍ زمني (نصف عمر لكل دوري) + أسبقيات الموسم السابق (ridge) | آخر ~1000 نتيجة |
| Pi-ratings ديناميكية (هجوم/دفاع) مع انكماش بداية الموسم | نفس النتائج |
| Elo بهامش الأهداف مع انكماش أول 8 جولات وبذر الصاعدين من متوسط الهابطين | نفس النتائج |
| فورم متعدد النوافذ (3/5/10) + ازدحام | نفس النتائج |
| سياق λ بعد التعديلات (context) — كل مضاعف خلف علم ablation | H2H / عشب / تكتيك / طقس / لاعبين / حكم |

**المرساة (pf)** — `pf = logit_pool(pm, ps, α)` حيث `ps` هو Pinnacle/Betfair منزوع الهامش
(Shin أو Power يُختار لكل دوري). α = وزن النموذج، يُقدَّر لكل دوري ولا يُقبل إلا إذا أثبت
bootstrap مقترن أن الدمج يتفوّق على السوق؛ **α = 0 ⇒ السوق وحده**. السوق لا يدخل اللبّ.

**غربال «المحسوم»** (`python/engine/sieve.py`) — طبقة قرار لا تغيّر الاحتمالات:
اتفاق الجهة بين اللبّ والسوق، `pf ≥ θ` (θ لكل دوري، تُرفع فقط)، فجوة ≤ 8 نقاط، السوق ≥ 55٪،
فارق ≥ 20 نقطة عن الثانية، رأس تعادل مستقل < 30٪، لا ديربي، لا غياب ركيزة، لا صاعد في أول
8 جولات، عينة موسم ≥ 6 لكل طرف. الشرائح: `banker` / `alt-market` / `weak` / `excluded`.

**القياس** — ثلاث لقطات لكل توقع (`prediction_timeline`: announce / lineup / close)، تقييم
يومي مقابل الإغلاق (`daily_metrics`) بمقياسين منفصلين (تغطية / محسوم)، حوادث المحسوم
(`banker_incidents`)، سلاسل «الفائزين المتكررين» (`team_streaks`)، ورفع θ آلي عند تراجع
الإصابة دون المُعلَن. الحزام التاريخي (`scripts/backtest.py`) walk-forward موسمي منذ 2022 مع
ablation وشبكة نصف العمر؛ `--apply` يكتب `league_calibration` ويبذر `fit_params_<league>`.

يتضمن المحرك أيضاً: تأثير لاعب/تشكيلة، ازدحام الكؤوس، أسواق O2.5/BTTS بحرارة ثنائية،
DC موازٍ على التسديدات وxG تتبّعي (Understat للخمس الكبرى)، وموديل حي.

**ما لا تفعله المنصة:** لا تنبيهات +EV ولا حصص كيلي (الحافة تُحسب للتشخيص فقط)، لا ادعاء 80٪
على كل المباريات، لا اختلاق إغلاق من السعر الأول.

## البيانات

- نتائج تاريخية: [football-data.co.uk](https://www.football-data.co.uk/)
- xG تتبّعي: Understat (الخمس الكبرى)
- جداول الموسم: fixturedownload.com (+ أودز قادمة من fixtures.csv و API-Football)
- إثراء: FotMob (غيابات/تشكيلات) · Open-Meteo (طقس) · إحداثيات الملاعب في `scripts/data/stadiums.json`
- الشعارات: TheSportsDB → `public/crests`

قاعدة البيانات: `data/taqdeer.db`.

## التشغيل

يتطلب Node ‏22–24 (`.nvmrc`).

```bash
cp .env.example .env          # FOOTBALL_DATA_API_KEY · API_FOOTBALL_KEY · Telegram اختياري

python3 -m venv .venv
.venv/bin/pip install -r requirements.txt

bun install
bun run pipeline              # مزامنة → تدريب وتوقع
bun run enrich                # أودز/طقس/FotMob/Understat xG
bun run dev                   # http://localhost:3000
```

| الأمر | الوظيفة |
|-------|---------|
| `bun run sync` | مصادر + جدول + كروت + مقالات + أخبار |
| `bun run enrich` | دورة إثراء (أودز/طقس/FotMob/xG) |
| `bun run fit` | تدريب النماذج وكتابة التوقعات (يستهلك معاملات الحزام إن طُبِّقت) |
| `bun run repredict` | إعادة توقع المباريات ذات التشكيلة المؤكدة (لقطة lineup) |
| `.venv/bin/python scripts/backtest.py --apply` | الحزام التاريخي walk-forward؛ `--ablation` / `--half-life-grid` / `--apply-report <json>` |
| `.venv/bin/python scripts/evaluate_daily.py` | التقييم اليومي مقابل الإغلاق + الحوادث + السلاسل + رفع θ (يعمل داخل `mlops_pipeline`) |
| `bun run check` | فحوص TS + `python -m engine.selftest` + eslint |
| `bun run telegram` | بوت أوامر؛ البث التلقائي بـ `TELEGRAM_BROADCAST=1` |

## الصفحات

| المسار | الوظيفة |
|--------|---------|
| `/` | الاستوديو: مباراة تالية + المحسوم + نتائج |
| `/leagues` | الدوريات |
| `/match/[id]` | 1X2 + تفكيك + خريطة نتائج + أسواق + مسار التوقع (إعلان/تشكيلة/إغلاق) + حكم الغربال |
| `/hasr` | المحسوم: غربال بقواعد ظاهرة، θ وα لكل دوري، أسباب الإسقاط |

| `/methodology` | شرح النماذج والحدود |

`/value` أُوقفت وتُحوَّل إلى `/hasr`.

## حدود معروفة

- على الحزام 2022→2026 لم يتفوّق اللبّ على إغلاق بيناكل في أي دوري (Δlog-loss ≈ −0.02…−0.04)،
  لذا α = 0 حالياً: الاحتمال المنشور هو السوق منزوع الهامش، ودور النموذج في λ والأسواق البديلة
  والغربال. شريحة «المحسوم» تاريخياً 72–80٪ إصابة عند θ لكل دوري بعينة 80–210 مباراة/دوري.
- Pinnacle توقّفت عن نشر أسعار الإغلاق في CSV منذ 2026-01؛ البديل بورصة Betfair (BFEC*) ثم
  الالتقاط الحي قبل الصافرة.
- لا «محسوم» قبل 6 مباريات لكل طرف في الموسم — أول جولات الموسم تُنشر كإشارة ضعيفة.
- xG التتبّعي يغطي الخمس الكبرى فقط؛ الباقي shot-proxy.
- PPDA تقريبي / تأثير اللاعب من دقائق التشكيلة — ليست بيانات Opta كاملة.
- الأودز والإثراء تغطي النافذة القريبة (أيام–أسبوعين) لا كل مباريات الموسم دفعة واحدة.
- الفرق الصاعدة تُبذر من متوسط تقييمات الهابطين لا من 1500 الأعمى.
